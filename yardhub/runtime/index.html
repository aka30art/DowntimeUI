ONE-TIME · CLEAR USER / STAFF DIRECTORY

This permanently removes every USER account except the existing DEV account, all STAFF roster entries and profiles, every object in the dedicated STAFF photo bucket, and every original PNG in the GitHub STAFF originals library. DEV keeps the same immutable USER ID, PIN credentials and current session. DEV1 and ADMIN are created as protected ROOTED role definitions only — not login accounts and not STAFF identities. Ordinary YARD ROLE definitions, access rights, department permission matrices, operational records, audit history and non-STAFF evidence remain intact. Historical audit entries may retain prior actor labels; provider backups and GitHub commit history may retain deleted bytes until their respective retention or history-purge windows expire.
