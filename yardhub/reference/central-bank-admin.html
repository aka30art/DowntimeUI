SEPARATION OF RESPONSIBILITIES

YARD ROLE permissions stay separate

User identities and ROOTS governance remain outside this control room. Legacy account-tier permission editing is retired; operational department permissions are governed by canonical YARD ROLE. This control room does not create users, edit PINs or duplicate the permission editor. Only the immutable DEV USER may access the Central Data Bank configuration control plane and manage global configuration. DEVACC retains locked root-equivalent operational permissions only; it is not a ROOTS identity and has no Central Data Bank or ROOTS governance authority. Only DEV may assign DEVACC. DEV1 may assign ADMIN ROOTS; ADMIN cannot assign ROOTS. ROOTS authority and ordinary YARD ROLE permissions are separate.

Application Structure Manager

Manage the YARD HUB launcher hierarchy and R&M machinery categories. Rename departments and machine categories, add or remove menu entries, and publish consistent generated navigation without changing permanent data identities.

VERSIONED CONFIGURATION
SAFE STRUCTURE MANAGEMENT

Changes remain drafts until validated, impact-reviewed and published. Department IDs and existing application routes stay stable. The DOWNTIME launcher identity and label remain locked. R&M and HUB SETTINGS cannot be deleted; R&M can be hidden from the YARD HUB menu. Existing R&M machine keys, records, permissions and API routes remain unchanged while category labels are managed here. Custom YARD HUB departments and R&M categories can be removed from their menus without deleting operational records. New custom entries open generated placeholder workspaces until dedicated module functionality is assigned. YARD HUB and R&M consume only the published structure through an authenticated read-only endpoint; DOWNTIME tracker logic, records, permissions and operational workflows remain untouched.

Departments

Each department becomes a standard YARD HUB menu tile. Drag-free ordering is controlled with MOVE UP / MOVE DOWN. Existing R&M machine types such as Telehandler and 360 Excavators are managed in the dedicated R&M category panel below so their permanent data keys and workflows stay intact.

R&M machinery categories

Rename existing machinery categories without changing their permanent data keys. Hide categories from the selector without deleting their records. New custom categories generate a standard placeholder tile until a dedicated R&M data workflow is assigned.
